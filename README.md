# Amala & Palmwine Festival website

A responsive, mobile-friendly static landing page for the Amala and Palmwine Festival.

## Current foundation

- Single-page festival landing site in `index.html`
- Responsive navigation and layouts
- Festival story, experience highlights, event-details section, and participation enquiries
- No invented date, venue, ticket price, or programme details

## Preview locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Before launch

Replace the temporary participation email address in `index.html` with the festival's official contact address. Add confirmed event date, venue, ticketing provider, official social links, approved logo, photography, sponsors, vendors, performers, and programme details.

## Deployment

This is a static site and can be hosted with GitHub Pages or any static hosting provider. For GitHub Pages, configure the repository's Pages settings to deploy from the `main` branch and the root folder.
